# Адвент-календарь дизайнера

Страница: https://vitadidesign.tilda.ws/ngdesign

Лендинг собирается из двух частей:

1. **Основной код** (`advent.js`). Вставляется в Тильду один раз и больше не меняется.
2. **Окошки**. Для каждого дня — маленький отдельный блок с текстом диалога. Новые дни добавляются новыми блоками, основной код при этом не трогается.

## 1. Основной код (блок T123 «HTML-код»)

```html
<div id="advent"></div>
<script src="https://a7778440006-web.github.io/vitadidesign/ngdesign/advent.js"></script>
```

В настройках страницы фон — `#FBF6ED`, шапку и подвал Тильды отключите.

## 2. Окошко дня (отдельный блок T123 под основным)

```html
<script>
(window.ADVENT_DAYS = window.ADVENT_DAYS || []).push({
  day: 3,                                   // номер окошка
  topic: 'Чек-лист визуала',                // тема — показывается на карточке после открытия
  title: 'Заголовок — название темы',       // заголовок в диалоге
  text: 'Текст окошка. Можно с <b>тегами</b> и абзацами <p>…</p>',
  media: 'https://…/preview.webp',          // картинка, гиф или видео .mp4 (можно оставить пустым)
  figma: 'https://www.figma.com/…',         // ссылка на файл в Figma
  figmaLabel: 'Ссылка в figma',             // текст кнопки (необязательно)
  download: 'https://…/file.pdf',           // ссылка «Скачать»
  files: 'Файлы в формате PDF, 12 Мб'       // подпись рядом с кнопками
});
</script>
```

* Если кнопка не нужна — `figma: false` или `download: false`.
* Окошко само откроется в 00:00 по Москве в свой день. Блок можно добавить заранее.

## Тестовые режимы

* `test: 'open'` — окошко доступно сразу, независимо от даты. После нажатия станет «уже открыли».
* `test: 'opened'` — окошко всегда показывается как «уже открыли».
* Перед запуском 1 декабря строку `test` у окошек 1 и 2 нужно удалить.
* Посмотреть сайт «как в другой день»: добавьте к адресу `?advent_date=2026-12-10`.
* Сбросить свои «уже открыли»: в консоли браузера `ADVENT.reset()`.
